Flex-Height Layout with Sticky Properties Panel

This reference app demonstrates the form editor embedded in a page that scrolls naturally (no fixed viewport height). The properties panel on the right uses position: sticky so it stays visible as you scroll through long manifests. Load the Patient Intake or Project Proposal manifests for large forms that exercise vertical scrolling.
